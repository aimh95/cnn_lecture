01

CNN은 왜 이렇게 생겼나

지금까지 배운 신경망은 완전연결(Fully Connected) 구조였습니다. 이전 층의 모든 뉴런이 다음 층의 모든 뉴런과 연결됩니다. 하지만 네트워크가 반드시 이렇게 한 줄로만 연결될 필요는 없습니다 — 입력을 여러 조각으로 나누어 같은 연산을 반복 적용한 뒤 다시 합칠 수도 있습니다. CNN은 이 발상에서 출발합니다.

국소 수용장(Receptive Field)

1959~1962년 Hubel과 Wiesel은 고양이의 시각 피질을 연구하며, 뉴런 하나가 시야 전체가 아니라 특정 위치의 작은 영역에만 반응한다는 사실을 발견했습니다. 이 제한된 입력 영역을 수용장(receptive field)이라 부릅니다. CNN은 이미지 전체를 하나의 거대한 벡터로 다루는 대신, 작은 영역을 훑는 필터(filter)를 이미지 곳곳에 반복 적용해 이 생각을 계산 모델로 옮깁니다.

핵심 파이프라인 입력 이미지 → CONV(국소 특징 추출) → ReLU → POOL(공간 축소) → … 반복 … → FC → Softmax → 클래스 확률
02

합성곱 연산의 동작

이미지는 3차원 텐서다

32×32 컬러 이미지는 가로·세로 32, RGB 3채널을 가진 32×32×3 텐서입니다. 마지막 숫자 3은 공간적 깊이가 아니라 채널 수입니다.

필터 하나가 숫자 하나를 만든다

필터는 입력의 작은 영역(예: 5×5)을 봅니다. 이때 필터의 깊이는 항상 입력의 채널 수와 같아야 합니다 — 5×5 필터가 3채널 입력을 본다면 필터 모양은 5×5×3이 됩니다. 5×5는 우리가 고르는 하이퍼파라미터지만, 깊이 3은 선택이 아니라 입력에 의해 강제되는 값입니다.

필터가 한 번 패치를 보면, 대응하는 75개(5×5×3) 입력값과 75개 가중치를 각각 곱해 더하고 편향을 더해 스칼라 값 하나를 만듭니다.

z = Σ Wᵢⱼₖ Xᵢⱼₖ + b  →  a = ReLU(z) = max(0, z)
완전연결층의 Wx+b와 본질적으로 같은 식입니다. 차이는 입력 전체가 아니라 작은 패치에 적용한다는 점뿐입니다.

가중치 공유(Weight Sharing)

필터를 옆으로, 아래로 이동시키며 이미지 전체를 훑을 때 같은 가중치를 재사용합니다. 세로 경계를 찾는 필터라면 그 경계가 이미지 왼쪽에 있든 오른쪽에 있든 같은 필터로 찾아야 하기 때문입니다. 위치마다 별도의 가중치를 쓰지 않으므로 완전연결층보다 파라미터가 크게 줄고, 같은 특징을 어느 위치에서든 탐지할 수 있습니다.

필터 여러 개 → 깊이 있는 출력

서로 다른 가중치를 가진 필터를 여러 개 사용하면 필터 개수만큼 활성화 맵이 쌓입니다. 5×5×3 필터를 6개 쓰면 출력 깊이는 6이 됩니다. 층을 거듭할수록 앞쪽은 색·방향성 있는 선 같은 저수준 특징을, 뒤쪽은 질감과 부분 형태 같은 고수준 특징을 학습하는 경향이 있습니다.

03

학습된 필터는 무엇을 보는가

CNN의 합성곱은 새로운 연산이 아닙니다 — Sobel 연산자, 가우시안 블러처럼 영상처리에서 손으로 설계해 온 커널과 형태가 완전히 같습니다.

Sobel이든 가우시안이든 CNN의 필터든, 결국 모두 z = ΣW·X + b 하나의 식입니다. 차이는 단 하나, 가중치 W를 사람이 손으로 정하느냐, 역전파로 데이터에서 학습하느냐뿐입니다. 아래 세 커널은 실제로 영상처리에서 쓰여 온 손 설계 필터입니다 — CNN의 3×3 필터와 크기·연산 방식이 동일합니다.

왼쪽 3×3 파란 테두리가 지금 커널이 올려진 위치입니다. 경계(9→0으로 바뀌는 3·4열 사이)를 지날 때만 큰 음수 반응(-36)이 나오고, 색이 균일한 영역에서는 0이 나옵니다 — 이것이 Sobel이 "경계를 찾는다"는 말의 실제 의미입니다.

CNN이 실제로 학습해낸 것 AlexNet 논문(Krizhevsky et al., 2012)이 시각화한 CONV1의 11×11×3 필터 96개를 보면, 그중 상당수가 방향성 있는 경계 검출기(Sobel과 유사한 패턴)나 부드러운 색 얼룩(blob)(가우시안 블러와 유사한 저주파 패턴)처럼 보입니다. 누구도 "엣지를 찾아라", "노이즈를 지워라"라고 지정하지 않았지만, 역전파가 데이터만으로 이런 값을 스스로 찾아낸 것입니다.

정리하면 Sobel·가우시안은 사람이 "정답"으로 고정해 둔 필터 한 종류이고, CNN의 CONV1은 이런 필터를 포함해 훨씬 넓은 필터 후보군을 데이터로부터 탐색하는 것입니다. 뒤쪽 층으로 갈수록 이렇게 학습된 저수준 엣지·블롭들이 조합되어 눈, 바퀴 같은 더 복잡한 개념으로 발전합니다.

04

차원 변화와 파라미터 수

층을 하나 통과할 때마다 텐서의 가로·세로·깊이가 어떻게 바뀌고, 그 층이 학습하는 파라미터가 몇 개인지 계산하는 방법.

출력 공간 크기 공식

입력 크기 N, 필터 크기 F, 스트라이드 S, 패딩 P가 주어지면 한 축의 출력 크기는 다음과 같습니다.

출력 크기 = ⌊ (N + 2P − F) / S ⌋ + 1
가로·세로 각각 같은 공식이 적용되며, 스트라이드 1·필터 홀수 F에서 P = (F−1)/2로 두면 입력과 출력 크기가 같아집니다(3×3→P1, 5×5→P2, 7×7→P3).
NFSP계산출력
7310(7−3)/1+15
7320(7−3)/2+13
7311(7+2−3)/1+17 (same)
7330(7−3)/3+1 = 2.33✕ 부적합

깊이(채널)는 별개 규칙

공간 크기는 N·F·S·P가 결정하지만, 출력 깊이는 오로지 사용한 필터의 개수 K로 결정됩니다. 반대로 필터의 깊이는 입력 채널 수에 종속되어 자유롭게 정할 수 없습니다.

학습 파라미터 수 — 가중치 공유의 대가

필터 하나가 F×F×C개의 가중치와 편향 1개를 갖고, 필터가 K개면 그 층의 전체 파라미터는 다음과 같습니다. 공간 위치 수와는 무관하다는 점이 핵심입니다 — 같은 필터를 모든 위치에서 재사용하기 때문입니다.

파라미터 수 = (F × F × C + 1) × K
완전연결층이었다면 위치마다 별도 가중치가 필요해 파라미터가 폭발적으로 늘었을 것입니다.

05

합성곱의 하이퍼파라미터

설계자가 CNN 연산에서 직접 조정하는 값 네 가지 — 이 값들이 출력의 모양과 파라미터 수를 함께 결정합니다.

F
필터(커널) 크기
수용장의 크기. 일반적으로 3×3, 5×5, 7×7, 11×11 등 홀수를 사용. 클수록 한 번에 넓은 영역을 보지만 파라미터와 연산량이 늘어남.
S
스트라이드(Stride)
필터가 한 번에 이동하는 칸 수. 커질수록 필터가 방문하는 위치가 줄어 출력 공간 크기가 작아지고 다운샘플링 효과가 생김.
P
패딩(Padding)
입력 테두리에 0을 덧붙이는 두께. 반복된 합성곱으로 공간 크기가 계속 줄어드는 것을 막고, 가장자리 정보를 충분히 활용하게 함(zero padding).
K
필터 개수
서로 다른 패턴을 찾는 필터를 몇 개 병렬로 쓸지. 출력 깊이(채널 수)를 그대로 결정하며, 층의 표현력과 파라미터 수를 좌우함.
주의 — 하이퍼파라미터가 아닌 것 필터의 깊이는 설계자가 정하는 값이 아닙니다. 한 필터는 현재 위치의 모든 입력 채널을 동시에 봐야 하므로, 깊이는 항상 입력 채널 수와 자동으로 일치합니다.
06

풀링(Pooling)

풀링은 각 채널의 특징 맵을 독립적으로 다운샘플링합니다. 가로·세로는 줄이지만 채널 수는 그대로 유지합니다. 계산량과 메모리를 줄이고 작은 위치 변화에 덜 민감한 표현을 만들지만, 정보를 버리는 연산이라는 점도 함께 기억해야 합니다.

풀링에도 필터 크기와 스트라이드 하이퍼파라미터가 있습니다(가장 흔한 설정은 2×2, 스트라이드 2). 다만 평균이나 최댓값을 고르는 정해진 규칙만 사용하므로 학습되는 가중치·편향은 없습니다.

07

완전연결층과 Softmax

합성곱과 풀링을 반복하면 작은 크기의 여러 특징 맵이 남습니다. 예를 들어 최종 출력이 3×3×10이라면 숫자는 90개입니다. 이 3차원 출력을 한 줄의 벡터로 펼치는 과정을 flatten이라 합니다.

펼쳐진 벡터를 완전연결층에 통과시키고, 마지막 층에서 클래스 수만큼 점수를 만든 뒤 Softmax로 확률 분포로 변환합니다. 정리하면 CNN의 앞부분(CONV+POOL)은 특징을 추출하고, 뒷부분(FC+Softmax)은 그 특징으로 최종 분류를 결정합니다.

08

대표 구조 연혁

같은 블록(CONV·POOL·FC)을 어떻게 조합했는지에 따라 CNN의 계보가 갈립니다. 각 구조를 외우기보다, 바로 이전 세대의 어떤 한계를 어떻게 바꿨는지, 그리고 대표 버전의 파라미터 수가 어떻게 변했는지를 기준으로 읽는 연습이 목표입니다.

모델대표 파라미터 수기존 대비 핵심 변화
LeNet-5약 6만CNN의 기본 구조 확립
AlexNet약 6,100만LeNet보다 약 1,000배 커지고 실제 사진 1,000종 분류에 성공
VGG-16약 1억 3,800만큰 필터를 3×3 여러 개로 바꾸고 16층으로 깊어짐
GoogLeNet약 680만병렬 다중 크기 필터와 1×1 Conv로 VGG보다 파라미터 95% 감소
ResNet-50약 2,560만residual connection으로 50층 이상을 안정적으로 학습
ResNet-152약 6,020만VGG보다 파라미터가 적으면서 152층 학습

DenseNet-121약 800만이전 모든 특징을 재사용해 ResNet-50보다 파라미터 약 69% 감소
DenseNet-201약 2,000만ResNet-152보다 깊지만 파라미터는 약 67% 적음

파라미터 수는 출력 클래스 수와 구현에 따라 달라질 수 있습니다. 위 표는 ImageNet 분류용 대표 모델과 원본 U-Net 기준의 대략적인 수치입니다.

핵심 결론 CNN은 발전하면서 파라미터가 계속 증가한 것이 아닙니다. AlexNet·VGGNet까지는 모델을 크게 만드는 방향이었지만, GoogLeNet 이후에는 더 적은 파라미터로 더 깊고 효율적인 모델을 만드는 방향으로 발전했습니다.

벤치마크로 보는 성능

비교에서 제외 — 과제가 다름 LeNet-5는 MNIST 손글씨 숫자(10클래스) 분류, U-Net은 의료 영상 픽셀 단위 분할(segmentation)이 과제입니다. U-Net의 IoU를 AlexNet의 Top-1 정확도와 직접 비교하면 안 됩니다 — 데이터와 문제, 평가 지표 자체가 다릅니다. 아래 벤치마크는 ImageNet-1K 분류 과제를 공유하는 7개 모델만 비교합니다.

LeNet-5 1998
Yann LeCun 등 · 손글씨 숫자(우편번호) 인식
이미지의 공간 구조를 활용하며 파라미터를 공유하는, 현대 CNN의 기본 형태를 정립.
이전 한계 일반적인 완전연결 신경망은 이미지의 모든 픽셀을 모든 뉴런과 연결했습니다. 이미지가 조금만 커져도 파라미터가 폭발했고, 가까운 픽셀끼리 연관되어 있다는 이미지 고유의 구조도 전혀 활용하지 못했습니다.

LeNet-5는 CONV → POOL → CONV → POOL → FC 구조로, 작은 필터로 가까운 픽셀의 패턴을 추출하고 같은 필터를 이미지 전체에서 공유하며, Pooling으로 특징 맵 크기를 줄였습니다. 입력은 MNIST 계열의 32×32 흑백 숫자 이미지, 분류 대상은 0~9 10개 클래스였습니다.

입력 32×32×1 학습층 5개 (Conv3+FC2) 필터 5×5, stride 1 파라미터 약 6만

32×32×1 흑백 입력에 5×5 필터 6개(stride 1, pad 0)를 적용하면 28×28×6이 되고, 2×2 풀링(stride 2)으로 14×14×6까지 줄어듭니다. 이 과정을 반복해 채널을 늘리고 공간을 줄인 뒤 FC층에서 숫자 클래스를 출력합니다.

정확한 기여 이미지의 공간 구조를 활용하면서 파라미터를 공유하는 현대 CNN의 기본 형태를 정립했습니다.
AlexNet 2012
Krizhevsky, Sutskever, Hinton · ILSVRC 2012
작은 숫자 인식용 CNN을 약 120만 장·1,000개 클래스의 실제 사진 분류(ImageNet)로 확장.
이전 한계 LeNet은 배경이 거의 없는 작은 흑백 이미지, 10개 클래스, 약 6만 장의 학습 데이터라는 단순한 문제에 쓰였습니다. 이 구조가 복잡한 실제 사진에서도 통할지는 확인되지 않은 상태였습니다.

AlexNet은 LeNet보다 합성곱층을 더 많이 쌓고 채널 수를 크게 늘렸으며, GPU로 학습하고 ReLU를 사용했습니다. Dropout과 데이터 증강으로 과적합도 억제했습니다. ReLU를 발명했다기보다, 대규모 CNN에서 성공시켜 널리 확산시킨 사례에 가깝습니다.

정확한 기여 작은 숫자 인식에 쓰이던 CNN을 약 120만 장·1,000개 클래스의 실제 사진 분류 문제로 확장해, CNN이 기존 영상 인식 방법보다 뛰어남을 증명했습니다.
VGGNet 2014
Simonyan, Zisserman · ILSVRC 2014
거의 모든 합성곱을 3×3으로 통일해 반복 적층 — 큰 필터 하나 대신 작은 필터+깊이로 표현력을 확보.
이전 한계 AlexNet은 11×11, 5×5처럼 큰 필터로 시작해 레이어마다 커널 크기와 설정이 달라 구조에 일관성이 부족했습니다. 학습층도 8개 정도로, 오늘날 기준으로는 깊지 않았습니다.

VGGNet은 11×11 → 5×5 → 3×3처럼 섞어 쓰던 AlexNet과 달리 3×3 → 3×3 → 3×3만 반복해서 쌓았습니다. 3×3 합성곱 두 개를 쌓으면 약 5×5 영역을 볼 수 있으면서, 그 사이에 ReLU가 여러 번 들어가 더 복잡한 표현을 학습합니다. 깊이도 AlexNet의 8층에서 VGG-16의 16층, VGG-19의 19층으로 늘어났습니다.

AlexNet 약 6,100만 → VGG-16 약 1억 3,800만 약 2.3배 증가(+약 7,700만) — 역시 대부분 FC층
깊이 16~19층 (VGG-16/19) 필터 3×3 고정 구조 단순·통일
정확한 기여 큰 합성곱 필터 대신 작은 3×3을 반복하고 깊이를 늘리는 설계가 효과적임을 보여줬습니다. VGG 이후 3×3 합성곱이 CNN의 사실상 표준 필터가 됐습니다.
GoogLeNet (Inception) 2014
Szegedy 등 · ILSVRC 2014 우승
여러 크기의 필터를 병렬로 사용하면서 1×1 합성곱과 Global Average Pooling으로 파라미터를 대폭 절감.
이전 한계 AlexNet·VGGNet은 한 층에서 정해진 크기의 필터만 사용했습니다. 또한 모델을 깊고 넓게 만들수록 파라미터와 연산량이 급격히 늘어 VGG-16은 약 1억 3,800만 개까지 커졌습니다. VGGNet과 GoogLeNet은 같은 2014년 계열이라 직접적인 후속작은 아니지만, 구조적 지향점은 뚜렷이 다릅니다.

GoogLeNet은 하나의 입력을 1×1, 3×3, 5×5 합성곱과 풀링에 동시에 병렬로 통과시킨 뒤 채널 방향으로 이어붙이는 Inception 모듈을 반복 적층합니다. 작은 물체와 큰 물체에 필요한 서로 다른 크기의 특징을 한 단계에서 함께 추출할 수 있습니다. 비싼 3×3·5×5 연산 앞에는 1×1 합성곱을 넣어 채널 수를 먼저 줄이는 병목(bottleneck) 구조를 썼고, 마지막의 거대한 FC층은 Global Average Pooling으로 대체했습니다.

VGG-16 약 1억 3,800만 → GoogLeNet 약 680만 약 95% 감소 (AlexNet 대비로도 약 89% 적음)
깊이 22층 Top-5 오류 6.7% 핵심 1×1 병목 + GAP
정확한 기여 여러 크기의 필터를 병렬로 사용하면서 1×1 합성곱과 Global Average Pooling으로 계산량과 파라미터 증가를 억제했습니다. GoogLeNet부터 CNN 발전의 방향이 "크게 만들기"에서 "효율적으로 깊게 만들기"로 바뀌기 시작했습니다.
ResNet 2015
He, Zhang, Ren, Sun · ILSVRC 2015 우승
덧셈 기반 skip connection으로 깊어질수록 학습이 어려워지는 문제를 해결, 100층 이상을 안정적으로 학습.
이전 한계 레이어를 깊게 쌓으면 이론적으로 더 복잡한 특징을 학습할 수 있지만, 실제로는 일정 깊이를 넘으면 학습 오차까지 증가하는 문제가 나타났습니다. 단순한 과적합이 아니라, 깊어진 네트워크 자체를 최적화하기가 어려웠던 것입니다.

ResNet은 일부 층을 건너뛰어 입력을 출력에 그대로 더하는 residual connection을 사용합니다. 기존 층은 목표 함수 H(x) 전체를 학습해야 했지만, ResNet의 중간 층은 입력에서 바뀌어야 하는 부분 F(x)만 학습하면 됩니다. 변경할 것이 없다면 F(x)를 0에 가깝게 만들면 입력 x가 그대로 전달되고, 역전파 그래디언트도 skip 경로를 통해 앞쪽까지 쉽게 전달됩니다.

ResNet-18약 1,170만
ResNet-34약 2,180만
ResNet-50약 2,560만
ResNet-101약 4,450만

VGG-16 약 1억 3,800만 → ResNet-152 약 6,020만 층은 약 9배 이상 깊지만 파라미터는 약 56% 적음

GoogLeNet의 680만보다는 ResNet-152가 약 8.9배 크지만, 핵심은 파라미터 효율이 아니라 152층짜리 네트워크를 실제로 학습 가능하게 만들었다는 점입니다.

깊이 최대 152층 Top-5 오류 3.6%

깊은 ResNet은 1×1(축소)–3×3–1×1(복원) 병목 블록을 사용해 표현력을 유지하며 연산량을 줄입니다 — GoogLeNet의 1×1 병목과 같은 발상입니다. 8-GPU 환경에서 2~3주 학습에도 불구하고, 추론 속도는 층이 8배 적은 VGGNet보다 오히려 빨랐습니다.

정확한 기여 덧셈 기반 skip connection으로 깊어질수록 학습이 어려워지는 문제를 해결하고, 100층 이상의 네트워크를 안정적으로 학습할 수 있게 했습니다.
U-Net 2015
Ronneberger, Fischer, Brox · MICCAI 2015, 의료영상 분할
Encoder의 세밀한 위치 정보를 같은 해상도의 Decoder에 직접 전달해 정밀한 픽셀 단위 예측을 가능케 함.
이전 한계 — 분류용 Encoder를 그대로 쓰면 Encoder는 Pooling·stride로 특징 맵을 계속 줄입니다(572→284→140→68→32). 공간 크기를 줄이면 "이미지에 무엇이 있는가"는 잘 알게 되지만, 물체의 정확한 위치와 경계 정보는 사라집니다. Decoder에서 다시 확대해도 이미 사라진 경계를 완벽히 복원하기는 어렵습니다.

U-Net은 앞의 분류 모델들과 직접적인 후속 관계가 아닙니다 — 이미지 전체를 분류하는 대신 픽셀마다 클래스를 예측하는 segmentation 모델입니다. Encoder에서 축소되기 전의 특징을 보관해뒀다가, 같은 해상도의 Decoder 특징과 채널 방향으로 이어붙입니다(concatenate). 그러면 Decoder는 깊은 특징에서 "무엇인지"를 알면서, 얕은 Encoder 특징에서 "정확히 어디인지"도 함께 알 수 있습니다.

파라미터 약 3,100만 구조 4단 다운 + 병목 + 4단 업 출력 입력과 같은 해상도의 분할 맵

U-Net을 ResNet·VGGNet과 파라미터만으로 비교하는 건 정확하지 않습니다 — 분류 모델과 달리 Encoder뿐 아니라 해상도를 복원하는 Decoder까지 포함하기 때문입니다. 단순 수치로는 VGG-16보다 약 77% 적고, ResNet-50보다 약 21% 많으며, GoogLeNet보다 약 4.6배 많지만, 애초에 수행하는 작업이 달라 파라미터 효율을 직접 비교할 대상은 아닙니다.

정확한 기여 Encoder에서 손실되는 세밀한 위치 정보를 같은 해상도의 Decoder에 직접 전달해 정확한 픽셀 단위 예측이 가능하도록 했습니다.
DenseNet 2016–17
Huang, Liu, van der Maaten, Weinberger · CVPR 2017 Best Paper
모든 이전 층의 특징을 현재 층에 직접 이어붙여 재사용, 깊이에 비해 훨씬 적은 파라미터를 사용.
이전 한계 — ResNet의 덧셈 ResNet은 이전 특징과 새 특징을 x_l = F(x_l-1) + x_l-1처럼 더합니다. 덧셈은 채널 수를 유지하지만 두 특징을 하나의 값으로 섞어버리고, 한 residual block이 직접 받는 것은 주로 바로 앞 block의 입력뿐입니다.

DenseNet은 특징을 더하지 않고 x_l = H_l([x₀, x₁, …, x_l-1])처럼 채널 방향으로 이어붙입니다(concat). 각 층은 이전 모든 층이 만든 특징에 직접 접근할 수 있습니다. 이미 있는 특징을 반복해서 새로 만들 필요가 없으므로, 각 층은 growth rate만큼의 채널만 새로 추가합니다 — growth rate가 32라면 층 하나가 256개·512개가 아니라 32개만 더합니다.

정확한 기여 모든 이전 층의 특징을 현재 층에 직접 제공해 특징 재사용과 그래디언트 전달을 강화하고, 깊이에 비해 훨씬 적은 파라미터를 사용하도록 만들었습니다.

U-Net은 DenseNet 구조를 먼저 가지고 있었나?

결론부터 말하면: U-Net은 DenseNet과 같은 concatenation 기반 스킵 연결을 먼저 사용했지만, DenseNet의 dense connectivity를 가지고 있었던 것은 아닙니다. 두 모델의 연결 밀도가 완전히 다릅니다.

항목U-NetDenseNet
직접 연결 대상대응하는 Encoder ↔ Decoder같은 block의 모든 이전 층
연결 빈도해상도 단계마다 한 번층마다 반복
연결 방식ConcatenationConcatenation
해결한 문제Downsampling으로 잃은 위치 정보특징 중복 학습과 그래디언트 전달
주요 용도SegmentationClassification backbone

U-Net은 Encoder 1이 Decoder 1에게만 이어지는 식으로, 같은 해상도끼리 단 한 번씩 선택적으로 연결됩니다. 목적은 위치 정보 복원입니다. 반면 DenseNet은 Layer 1이 Layer 2·3·4 모두에게 직접 이어지는 식으로, 같은 블록 안의 모든 층이 이후 모든 층과 연결됩니다. 목적은 특징 재사용과 깊은 네트워크의 학습 효율입니다.

비유 U-Net은 Encoder 건물과 Decoder 건물의 같은 층 사이에 다리를 놓는 것이고, DenseNet은 한 건물 안의 각 층을 이후의 모든 층과 직접 연결하는 것입니다.

U-Net이 DenseNet보다 먼저 나왔는데도 DenseNet이 별도의 기여로 인정받는 이유는, 연결 하나의 존재가 아니라 네트워크 전체의 연결 규칙을 새롭게 설계했기 때문입니다. U-Net은 DenseNet의 아이디어를 부분적으로 닮았지만, DenseNet은 U-Net의 이름만 바꾼 모델이 아닙니다.

직접 해보기 — 필터 실습

이미지 하나에 Sobel·가우시안을 즉석에서 돌려 보고, 진짜 역전파로 작은 CNN을 브라우저에서 학습시켜 필터가 무엇을 향해 수렴하는지 눈으로 확인합니다. 모든 계산은 이 페이지 안에서 즉시 실행됩니다.

이미지 선택

파란 계열은 양수, 주황 계열은 음수 반응입니다(Gx·Gy). 03장의 커널을 이 이미지에 그대로 적용한 결과입니다.

미니 CNN 학습시키기 실제 역전파로 학습(64×64 축소본)

입력
64×64×1 → Conv1
3×3, 필터 6개same pad, stride 1 → 특징 맵
64×64×6 → Leaky
ReLU음수 기울기 0.1 → Conv2
1×1, 6→1채널 가중합 → 출력
64×64×1예측 맵

학습 파라미터 수 = (3×3×1+1)×6 + (1×1×6+1)×1 = 60 + 7 = 67개 — 04장의 공식 (F×F×C+1)×K를 이 미니 CNN에 그대로 적용한 값입니다. Conv1이 3×3이라 Sobel과 같은 크기의 수용장이라, 필터가 수렴한 모양을 03장의 커널과 바로 비교할 수 있습니다.

학습 목표
Conv1 필터 6개 (3×3) — 가중치와 실제 통과 결과(활성화 맵)
Conv2 가중치 (1×1, 6채널 → 1채널)

"Sobel 엣지처럼"을 고르면 Conv1 필터들이 방향성 있는 경계 검출기 형태로, "가우시안 블러처럼"을 고르면 중심에 몰린 저역통과(평균) 형태로 수렴하는 경향을 보입니다. Conv2의 V₁~V₆은 각 Conv1 필터가 만든 특징 맵에 곱해지는 가중치, c는 편향입니다 — 이 여섯 숫자가 6장의 특징 맵을 하나의 예측 맵으로 합칩니다.

필터 중 일부가 유독 안 움직인다면 ReLU가 죽은(dying ReLU) 상태일 수 있습니다 — 어떤 필터의 출력이 모든 픽셀에서 음수이면 ReLU가 그 값을 전부 0으로 만들어 그래디언트도 정확히 0이 되고, 그 필터는 초기값에 영원히 멈춥니다. 이를 막기 위해 이 데모는 음수 구간에서도 기울기 0.1을 살려두는 Leaky ReLU를 사용합니다.

정리 체크리스트

  • 01입력 N, 필터 F, 스트라이드 S, 패딩 P가 출력의 공간 크기를 결정한다 — ⌊(N+2P−F)/S⌋+1.
  • 02필터의 깊이는 입력 채널 수와 같고, 출력 깊이는 필터 개수 K와 같다.
  • 03같은 필터를 모든 위치에 공유하므로 파라미터는 (F×F×C+1)×K — 공간 위치 수와 무관하다.
  • 04맥스 풀링은 채널별로 공간 크기만 줄이며 학습 파라미터가 없다.
  • 05GoogLeNet은 병렬 경로(Inception), ResNet은 덧셈 지름길(H(x)=F(x)+x)로 깊이 문제를 풀었다.
  • 06DenseNet은 지름길을 아예 촘촘한 연결(concat)로 확장했고, U-Net은 스킵 연결로 분류 대신 픽셀 단위 분할을 가능케 했다.
